# KashFlow — Gestion Financière Personnelle Intelligente

KashFlow permet de suivre les revenus, dépenses, budgets, objectifs d'épargne avec prévisions et résumés IA explicables.

## Architecture
- **Web Next.js/HTML5** : Dark financial dashboard, graphs budgets/dépenses, import CSV.
- **Backend Laravel 11 API** : Sanctum, aggrégations financial analytics, Redis cache.
- **Mobile Flutter** : Saisie ultra-rapide des dépenses, graphiques, mode hors-ligne.

## Database Tables
`users`, `accounts`, `transactions`, `categories`, `budgets`, `savings_goals`, `debts`, `recurring_rules`, `alerts`.
